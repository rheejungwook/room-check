# 회의실 점검 (모바일)

회의실 월 점검용 모바일 웹앱. `index.html` 한 파일로 동작하며 데이터는 각자 폰(브라우저)에만 저장됩니다.

## 사용
1. 링크 접속 → 이름·사옥·담당 층 선택
2. 층별로 O/X, 소모품 보충 수량 입력
3. 하단 [점검표 엑셀 내보내기 · 공유] → 사내 메신저로 전송
4. 취합 담당자: 설정 → [다른 사람 파일 취합하기]에서 받은 엑셀들을 합쳐 최종본 내보내기

## 배포 (GitHub Pages)
저장소 Settings → Pages → Branch: `main` / `/ (root)` → Save
